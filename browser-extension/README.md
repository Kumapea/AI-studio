# AI制片台 Chrome V4.2

Chrome 扩展只做一件核心事情：**剧本 → 场景语境 → AI导演深化 → LibTV Prompt**。

## 工作流
1. 先写大白话剧本。
2. 在「场景语境」里写时间、地点、人物位置、空间关系、关键道具等硬约束。
3. 需要特殊景别/运镜时可以直接写在剧本里，AI 必须优先保留。
4. 点击「AI导演深化」→「生成导演任务」。
5. 点击 DeepSeek / Kimi / GPT / Gemini，扩展自动打开对应网页并填入任务。
6. 用户最后检查并点击发送。

## 原则
- 用户负责说人话，AI负责懂影视。
- 场景语境是硬约束，不得擅自把车内改成沙发、客厅等其他场景。
- 不要求用户逐项填写景别、构图、机位、焦段、运镜。
- Chrome 版不再提供视频分析、爆款拆解、我的诊断、报告等研究功能。


V4.2 Chrome：只保留「提示词」与「剧本标注」两个入口。剧本标注保留部位（含面部/眼睛等）、景别、运镜、方位、情绪效果词库；右侧词汇双击可编辑。
