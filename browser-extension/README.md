# AI 视频制片台 · 浏览器扩展版

不需要任何 API Key，不用付费——指令和图片自己在本地配好，交给你已经在用
的 DeepSeek 网页版或 Kimi 网页版去问。Chrome 和 Edge 都能装，装法完全一样
（Edge 本来就是同一个内核，直接支持 Chrome 扩展）。

## 怎么安装（第一次，大概2分钟）

1. 把这个压缩包解压到一个你不会手滑删除的文件夹里（比如"文档"里新建一个
   `ai-video-studio-ext` 文件夹）。**注意：装好之后不能删这个文件夹**，扩展
   是直接从这个文件夹里读取的，删了扩展就没了。
2. 打开 Chrome（或 Edge），地址栏输入：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
   回车。
3. 页面右上角有个「开发者模式」开关，打开它。
4. 打开后左上角会出现一个「加载已解压的扩展程序」按钮，点击它。
5. 选择你刚才解压出来的那个文件夹（选到包含 `manifest.json` 那一层，不要
   多选或少选一层），点「选择文件夹」。
6. 装好了。浏览器工具栏右上角（拼图图标附近）会出现一个新图标，点一下——
   如果没立刻看到，先点一下工具栏的拼图图标，把它"图钉"固定出来。

## 怎么用

点工具栏图标，右边会弹出一个侧边栏——**这个侧边栏可以跟网页同时开着**，
一边是 DeepSeek/Kimi 或者抖音，一边是这个工具，不用来回切标签页。

**提示词精修**：大白话描述你想要的画面 → 生成精修指令 → 点「在 DeepSeek
中打开并填入」或「在 Kimi 中打开并填入」，会自动开一个标签页并尝试把指令
填进对话框（自动填入是尽力而为，网站改版可能会失败，失败了指令已经在
剪贴板里，自己粘贴一下就行，不影响使用）。

**视频分析**：
- 方式A：正在抖音网页看某个视频时，直接点「从当前抖音标签页抓取」——这
  个是实验性功能，靠抖音页面现在的结构去找视频，抖音以后改版可能失效，
  失效了会提示你，换方式B就行。
- 方式B：把视频文件（提前保存到本地的）直接上传，更稳，不依赖任何网站
  的页面结构。
- 两种方式都能自动截好几张关键帧图片，可以打包下载成 zip；分析指令的文
  字部分可以自动复制/填入 DeepSeek 或 Kimi，**但图片必须你自己手动拖进
  对话框**——这是浏览器的安全限制，任何网页脚本都没法帮你自动选文件，
  不是这个工具没做好。

**增长诊断 / 汇报生成 / 剧本标注**：跟之前一样，纯本地计算/生成，不需要
配合任何网站，直接填数据/内容就能用。

## 关于"实验性"功能的实话实说

「从当前抖音标签页抓取」和「自动填入 DeepSeek/Kimi 对话框」这两个功能，
原理是去读取网页当前的结构（找视频、找输入框），而不是通过官方接口，所以
没法保证 100% 稳定——网站随时可能改版。但每一个功能都有不依赖网页结构的
保底方式：
- 抓取关键帧失败 → 换成上传本地视频文件（方式B）。
- 自动填入对话框失败 → 文字已经复制到剪贴板，手动粘贴。
- 图片永远需要手动拖进 DeepSeek/Kimi，这个没有"自动"选项（浏览器不允许）。

工具本身的核心价值——那套七维拆解+运镜五变量的方法论——不受这些限制影响，
每次生成的指令都是完整的，这部分是稳定可靠的。

## 关于提示词精修的准确度

指令里会把七个维度（镜头/主体/动作/环境/光影/风格/运镜）和运镜的五个变量
都要求 DeepSeek/Kimi 落到具体数值和具体词汇，尽量避免"电影感""高级感"这
类空话，目的是让第一次生成的视频就比较接近预期，减少来回换 Prompt 重新生
成视频的次数。但最终效果还是取决于 DeepSeek/Kimi 当次的理解和你用的视频
生成平台本身的能力，没法保证 100% 一次就中——描述里给的细节越具体（主体
长什么样、动作是什么、光线是什么感觉），命中率越高。

## 常见问题

- **点了图标没反应 / 没弹出侧边栏**：先点一下工具栏的拼图图标，把这个扩展
  "图钉"固定到工具栏，再点它自己的图标。
- **"从当前抖音标签页抓取"提示找不到视频**：确认抖音那个标签页已经在播放
  一个视频（不是列表页），刷新一下抖音页面再试一次；实在不行换上传本地
  文件。
- **自动填入 DeepSeek/Kimi 失败**：文字已经复制到剪贴板了，切过去 Cmd+V /
  Ctrl+V 粘贴即可。
- **想卸载**：回到 `chrome://extensions`（或 `edge://extensions`），找到
  这个扩展，点「移除」即可，跟卸载普通软件一样简单。
